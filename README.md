## More than a scanner

### Scan with context

Kodex recognizes QR codes and common barcode standards, then presents actions that match the detected content. Open a link, join a Wi-Fi network, add a contact or event, call a number, send a message, copy the value, or share it—all without unnecessary steps.

### Create codes that look like yours

Build QR codes for text, URLs, email, phone numbers, SMS, Wi-Fi, locations, contacts, calendar events, and encrypted text. A live preview keeps every change visible while you refine colors, gradients, patterns, frames, and center content.

Barcode creation includes format-aware input rules, automatic check digits where supported, readable-value controls, sizing options, and safe visual customization.

### Analyze before you act

The on-device analyzer helps you understand what a code contains before opening it. It summarizes content type, checks common link and formatting signals, validates supported barcode structures, and clearly explains the scope of each result.

Analysis is guidance—not a guarantee of safety or authenticity—but it gives you more context for an informed next step.

### Build a library, not a pile

Every scanned or generated code can become part of a searchable library. Use smart folders for favorites, scanned items, generated items, and Trash; add custom folders and tags; then filter by code type or barcode format whenever the collection grows.

### Export without compromise

Download or share your designs as PNG, JPEG, or WebP. Choose standard resolution, 2× high resolution, or 4× ultra resolution when you need sharper results for print, presentations, packaging, or digital campaigns.

### Move your data on your terms

Create local `.kodex` backups and restore them whenever needed. Device Transfer moves codes, folders, and designs through an encrypted package protected by a one-time 8-digit code—no account or cloud transfer is required.

## Privacy-minded by design

- No account is required.
- Your code library and organization data are stored locally.
- Code analysis runs on the device.
- Backup files are created only in a location you choose.
- Device Transfer uses an encrypted package instead of a cloud account.
- Camera access is used only for scanning, and the app can still be installed on devices without a camera.

## Made for Android

Kodex feels at home on modern Android devices with Material 3, dynamic color on supported versions, light and dark themes, configurable startup behavior, reorderable navigation, home-screen widgets, and a Quick Settings scanner tile.

The app supports Android 9 and newer and is localized in 17 languages:

English, Turkish, Arabic, Bengali, Chinese, French, German, Hindi, Indonesian, Italian, Japanese, Portuguese, Russian, Spanish, Swahili, Urdu, and Vietnamese.

## Product technology

Kodex is built natively for Android with:

- Kotlin and Jetpack Compose
- Material 3 and dynamic color
- CameraX and ML Kit Barcode Scanning
- ZXing-based QR and barcode generation
- Room and DataStore for local persistence
- WorkManager for reliable backup and restore operations
- Glance for home-screen widgets
