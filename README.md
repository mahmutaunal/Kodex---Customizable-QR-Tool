# ✨ About

Kodex is a modern **QR Code & Barcode** application focused on creating beautiful, customizable and secure codes.

Whether you need to scan a QR code, generate a barcode, customize every visual detail or securely transfer your data to a new device, Kodex provides everything inside one elegant Material 3 experience.

Built entirely with **Jetpack Compose**.

## 📱 QR & Barcode

- Generate QR Codes
- Generate Barcodes
- Scan QR Codes

- Scan from Camera
- Scan from Gallery
- Smart Scan Actions
- Edit previously created codes

# 🛠 Built With

| UI | Jetpack Compose |
| Design | Material 3 |
